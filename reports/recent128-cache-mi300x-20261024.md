# DSV4 recent-128 cache: MI300X validation

Validation date: 2026-10-24 (Asia/Shanghai).

## Baseline and scope

- Repository: `RL-Align/RL-Kernel`, not the historical KLR fork.
- Main baseline, rechecked at validation time:
  `5ba769f681b7fa765ea6b29f9939454a858390ba`.
- This covers item 12 of the DSV4 ROCm cache work.
- Git history and the PR record determine publication status.
- Tests used one AMD Instinct MI300X VF, not eight GPUs or multiple nodes.

## Reused numerical implementations

1. vLLM `quantize_and_insert_k_cache`: quantization and paged writes.
2. vLLM `dequantize_and_gather_k_cache_triton`: paged reads and dequantization.
3. vLLM `combine_topk_swa_indices`: chronological recent-window indices and lengths.
4. Megatron mLite `quantized_main_k_visible`: native training-visible values and VJP.

RLK adds typed contracts, immutable metadata binding, request/version state and
framework adapters. It adds no quantization, gather, index, attention or backward
kernel and no second page allocator.

The framework retains prefix-plus-chunk pages until gather completes. Unsupported
configurations fail explicitly; a BF16-only cache is not substituted for the
FP8 target. A fused RoPE/cache writer must not be followed by a duplicate
post-RoPE update; see the integration documentation.

GPU coverage includes OCP/FNUZ, 64/128-token pages, full/chunked prefill, decode,
cross-page windows, permuted physical pages, mixed batches and ordering,
neighbor lengths, suffix padding, page reuse, read-only replay and no CPU
readback in the hot layer path. Tests compare data/scale bytes, indices and
lengths rather than substituting `allclose`.

The Megatron tests execute three **unmodified native helper function bodies**
from the pinned source, isolated from NVIDIA-only CSA imports. They validate
the helper/adapter forward and gradient, not a complete Megatron training run.

## Cache microbenchmark

Single-token decode; median of five loops of 100 iterations, synchronized wall
time including Python launch overhead. Binding is performed once per scheduler
step and shared across layers.

|Batch|Metadata bind/step (us)|Upstream write (us)|Upstream gather+indices (us)|RLK contract replay (us)|
|---:|---:|---:|---:|---:|
|1|503.8|15.4|50.5|73.4|
|8|314.3|15.2|49.6|77.2|
|32|301.4|15.9|49.4|86.6|

Contract checks add measurable Python overhead. These numbers are not presented
as a speedup, model throughput, or an attention-kernel benchmark.

## Reproduction

Use a compatible ROCm/vLLM DSV4 environment with the ABI documented in
`docs/models/deepseek_v4/recent128-cache.md`. Acquire the pinned native helper:

```bash
mkdir -p .codex-work/upstream
curl -fsSL \
  https://raw.githubusercontent.com/ISEEKYAN/Megatron-LM/327a238239448de6771beea185dc6902a8de3eaa/experimental/lite/megatron/lite/model/deepseek_v4/vllm/primitive/attention/runtime.py \
  -o .codex-work/upstream/megatron_runtime.py

RLK_MEGATRON_DSV4_RUNTIME_SOURCE="$PWD/.codex-work/upstream/megatron_runtime.py" \
  python -m pytest tests/contracts/operators tests/models/deepseek_v4 -q

python benchmarks/benchmark_recent128_cache.py \
  --iterations 100 --output .codex-work/benchmark.json
```

Without the source environment variable, helper-parity cases are explicit skips;
the recorded 200-test acceptance run supplied the source and had no skips.

## Not claimed

- Complete Flash-0731 and four-framework-path raw-logprob acceptance.
- C4/C128 compression, complete candidate composition, O/LSE or full attention backward.
- CP>1, multi-node operation, stateful Graph replay or shared-prefix COW.
- Automatic monkey-patching of a complete DSV4 model.

These are explicit integration/signoff boundaries, not silently substituted paths.
