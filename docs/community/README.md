# Community

RL-Kernel is developed in the open at:

- [GitHub repository](https://github.com/RL-Align/RL-Kernel)
- [Apache-2.0 license](https://github.com/RL-Align/RL-Kernel/blob/main/LICENSE)

Use GitHub issues and pull requests for bug reports, operator proposals, and documentation
improvements.

## Developer meeting

The community holds a weekly developer meeting on Google Meet, every Saturday
from 21:00 to 22:00 Beijing time (UTC+8, 13:00–14:00 UTC). The meeting covers
RFC task claims and development progress, problems contributors have run into,
and the plan for the next stage. Everyone interested in RL-Kernel is welcome
to join.

- [Google Meet link](https://meet.google.com/paf-mtkd-dbz) — the same link every week
- [Calendar link](https://calendar.app.google/rmJAz1Dnb4PfFKTz5)
